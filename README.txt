TI PAS - PHONE TEST / CLOUDFLARE PAGES

This folder is arranged as a static website:
- index.html          Welcome screen
- trail/index.html    The 17 Stepping Stones
- today/index.html    Today's Step - SDG 5
- garden/index.html   My Garden / Progress Journal

To publish with Cloudflare Pages:
1. Extract this ZIP on your computer.
2. Open a terminal in the extracted ti_pas_phone_site folder.
3. Run: npx wrangler pages deploy . --project-name=ti-pas --branch=main
4. Follow the login/authorization prompts if asked.
5. Open the deployment URL Cloudflare prints, then visit it on your phone.

Note: this is a static preview of the supplied screens. It does not add accounts,
cloud sync, or persistent habit tracking. Some visual controls may be mockups.
